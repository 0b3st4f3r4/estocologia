# H2b — dados reais com ambientes = intervenções conhecidas em X

Baixado em 2026-10-14 para refazer o portão de saída do H2 (ICP; Peters, Bühlmann & Meinshausen 2016, *citada de memória, conferir*).
Critério: o ambiente deve ser uma **intervenção documentada sobre um preditor X**, não sobre Y.
Todos os arquivos são dados não confiáveis: só inspeção leve com `python3 -I` fora desta pasta; nada foi executado a partir deles.
Integridade: `SHA256SUMS` (gerado com `sha256sum`, caminhos relativos a esta pasta).
Documentação original do Rdatasets (HTML) está em `docs/`.

Legenda da última coluna ("E age em Y?"): **baixo** = a intervenção plausivelmente só passa por X; **médio** = há canal direto plausível, mas é contornável com a escolha de Y/X; **alto** = viola a hipótese do ICP com probabilidade razoável.

## Recomendação para o ICP (ordem)

1. **Sachs 2005 (14 arquivos)** — o caso canônico; alvos de intervenção conhecidos, n grande por ambiente. Y = `P38`, `pjnk` ou `p44/42`.
2. **RAND HIE** — plano sorteado age sobre o preço (coparticipação), não diretamente sobre gasto; medicina/saúde.
3. **wooldridge::injury** — mudança de regra do teto de benefício, com grupo de controle; direito/trabalho.
4. **AER::USSeatBelts** e **AER::STAR** — boas como 4º/5º domínio (trânsito/política; educação), com a ressalva do canal direto.
5. Reserva / fracos: Fatalities, CigarettesSW, Cigar, njmin3, thornton_hiv, nsw_mixtape, Sachs discretizado.
