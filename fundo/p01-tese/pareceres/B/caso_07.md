# Parecer — Caso 07: aplicativo de sono por sexo

## Erro de raciocínio
"Significativo nas mulheres, não significativo nos homens" não demonstra que o efeito difere entre os sexos. Para isso é preciso testar a diferença entre os efeitos, ou seja, a interação.

## Resultados
- Mulheres: +17,5 min/noite (IC 95% de 3,9 a 31,1; p = 0,012). Homens: +8,2 min (IC de −8,2 a +24,6; p = 0,32). Os números se reproduzem.
- Os dois ICs se sobrepõem amplamente, e o efeito estimado nos homens é positivo. O IC dos homens é compatível com efeitos iguais ao das mulheres.
- Interação app × sexo (OLS): diferença de −9,3 min nos homens em relação às mulheres, IC 95% de −30,4 a +11,9, p = 0,39. Não há evidência de que o efeito seja diferente.
- Modelo sem interação, a análise mais adequada dado o desenho estratificado por sexo: efeito comum de +12,9 min (IC de 2,3 a 23,4; p = 0,017).
- Com 60 por braço em cada sexo, o estudo tem baixo poder para detectar uma interação desse tamanho. A ausência de significância nos homens é falta de precisão, não evidência de ausência de efeito.

## Implicação para a decisão
Não há base para reposicionar o produto só para mulheres nem para abandonar os homens. O que os dados indicam é um efeito modesto (~13 min/noite) no conjunto, sem diferença demonstrada por sexo.
